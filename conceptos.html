Conceptos fundamentales (variables, constantes, operadores)

Inicio

Los 3 Pilares del Código

Para construir cualquier pieza de software, necesitas tres bloques de construcción fundamentales: Variables para almacenar datos que pueden cambiar, Constantes para datos que deben permanecer fijos, y Operadores para realizar acciones y cálculos con esos datos.

1. Variables: Cajas de Datos Flexibles

Una variable es un contenedor etiquetado en la memoria donde puedes guardar información cuyo valor puede cambiar ("variar") durante la ejecución del programa. Son esenciales para el manejo dinámico de la información.

Ejemplo de una Variable

La variable contador se inicializa en 1 y luego se incrementa a 2, demostrando su mutabilidad.

□

let contador = 1;

Variable: contador

Valor Inicial: 1

contador = contador + 1; (Valor final: 2)

Los tipos de datos que almacenan las variables impactan en cómo se procesan. Esta gráfica muestra la distribución de los tipos fundamentales en la programación.

2. Constantes: Valores Inmutables

Una constante almacena un valor que, una vez asignado, no puede cambiar. Se utiliza para valores fijos como pi ($\pi$) o la tasa de impuestos, protegiendo el programa de modificaciones accidentales.

Variable vs. Constante

Una variable (nombre) puede cambiar, mientras que una constante (IVA) generará un error si se intenta reasignar.

☑

Variable (Flexible)

let nombre = "Laura";

nombre = "Ana"; (Permitido)

⚠

Constante (Fija)

const IVA = 0.16;

IVA = 0.18; (¡ERROR de reasignación!)

3. Operadores: Las Herramientas de Acción

Los operadores son símbolos que le dicen al programa que realice una operación específica. Son los "verbos" que actúan sobre las variables y constantes (los "sustantivos").

Aritméticos

Cálculos matemáticos.

+ (Suma) - (Resta) * (Multiplicación) % (Módulo)

Asignación

Guardan valores.

= (Asignar) += (Sumar y asignar) -- (Decremento)

Comparación

Comparan, devuelven Booleano.

== (Igualdad) != (Diferente) > (Mayor que) <= (Menor o igual)

Lógicos

Combinan condiciones.

&& (Y lógico - AND) || (O lógico - OR) ! (No lógico - NOT)

Ejemplo Integrado: Cálculo de Área

En este ejemplo, una Constante define el factor $\pi$ (3.1416), una Variable almacena el radio ($r$), y un Operador realiza el cálculo del área ($A = \pi \cdot r^2$).

const PI = 3.1416;

let radio = 5; // Variable: El radio puede cambiar


let area = PI * radio * radio;

// Operador * (aritmético) para multiplicar


radio = 10; // Actualizamos la variable

area = PI * radio * radio;

// El nuevo área es 314.16

Conceptos en Acción

  • Constante (pi): Garantiza que el valor matemático no se altere.
  • Variable (radio): Permite calcular el área de diferentes círculos sin modificar el código.
  • Operador ($ * $ y $ = $): Realiza la operación de multiplicación y la asignación del resultado final.
